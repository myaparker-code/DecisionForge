# DecisionForge

**COSC 208 — Discrete Structures Final Project**

## Project Overview
DecisionForge is an interactive web application that uses propositional logic to evaluate decisions and explain the results.

## Project Scenarios
- **Scenario A — CampusRoute:** A transportation decision-support tool that compares commuting options.
- **Scenario D — SecureSteps:** A cybersecurity login logic simulator.
